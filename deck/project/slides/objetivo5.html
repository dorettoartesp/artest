Objetivo 05

Modelos de linguagem no desenvolvimento interno

Contratar o acesso a grandes modelos de linguagem (LLM) para a equipe, em duas fases: assinatura de modelo comercial por API, com contrato direto com o provedor; em seguida, avaliação de modelo de pesos abertos hospedado pela agência, para os dados que não devam sair dela.

Aplicações para a ARTESP

Programação assistida, revisão, testes e documentação das aplicações da agência, não só do CCM.

Tratamento de dados

Extração, classificação e conferência de dados e documentos recebidos das concessionárias.

Documentos técnicos

Apoio à elaboração de termos de referência, planos e relatórios da gerência.

A aquisição de GPU para o modelo hospedado deverá ser avaliada com a equipe de infraestrutura da SUTID.
