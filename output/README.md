# Exportações versionadas

Uma pasta por versão da apresentação. Os arquivos aqui são cópias de referência; os publicados ficam em `site/docs/`.

| Pasta | Conteúdo | Origem |
|---|---|---|
| `v1/` | `plano-estrategico-ccm.pdf`, `plano-estrategico-ccm.pptx` | Exportação do deck de backup no claude.ai (tipo Slides), 02/10/2026, 32 slides |

Para uma nova versão: exportar PDF e PPTX do backup (ou gerar a partir de `site/`), criar `vN/`, copiar os arquivos com os mesmos nomes e atualizar esta tabela e `site/docs/`.
